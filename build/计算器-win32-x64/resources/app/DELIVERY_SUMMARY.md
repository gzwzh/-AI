## 🔧 配置选项

### 修改 API 端点

编辑 `src/config/api.ts`：
```typescript
export const API_BASE_URL = 'https://your-api-server.com'
```

### 修改轮询参数

编辑 `src/config/api.ts`：
```typescript
export const POLL_CONFIG = {
  INTERVAL: 3000,      // 轮询间隔
  TIMEOUT: 600,        // 轮询超时
  REQUEST_TIMEOUT: 10000  // 请求超时
}
```
