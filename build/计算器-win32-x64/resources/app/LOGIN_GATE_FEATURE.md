# 登录门槛功能文档

## 功能概述

实现了一个登录门槛机制，当未登录用户点击功能模块时，会弹出登录提示弹窗，引导用户完成登录后才能使用功能。

## 功能特性

### 1. 登录提示弹窗
- **触发条件**：未登录用户点击任何功能模块
- **弹窗内容**：
  - 标题：登录提醒（带登录图标）
  - 主文本：提示用户需要登录才能使用该功能
  - 信息框：说明点击按钮将打开登录页面
  - 立即登录按钮：黑色按钮，点击后启动登录流程
  - 底部提示：登录后即可使用所有功能

### 2. 登录流程
弹窗中的"立即登录"按钮会触发完整的登录流程：
1. 生成带签名的 nonce
2. 获取网页端登录地址
3. 打开浏览器登录页面
4. 轮询获取 token（1秒超时）
5. 获取用户信息并保存

### 3. 用户体验
- 已登录用户：直接点击模块导航到对应功能
- 未登录用户：点击模块弹出登录提示，可选择登录或关闭弹窗
- 弹窗可通过点击右上角 × 按钮或点击背景关闭

## 样式设计

### 弹窗外观
- 背景：半透明黑色遮罩（rgba(0, 0, 0, 0.5)）
- 弹窗：圆角卡片，白色背景（深色主题自适应）
- 最大宽度：500px，响应式设计

### 按钮样式
- 立即登录按钮：黑色背景，白色文字
- 悬停效果：背景变深，向上移动，增加阴影
- 点击效果：缩放反馈

### 动画
- 弹窗出现：淡入 + 向上滑动（0.3s）
- 遮罩出现：淡入（0.3s）

## 使用流程

### 用户未登录时
1. 用户点击功能模块
2. 弹出登录提示弹窗
3. 用户可选择：
   - 点击"立即登录"按钮 → 打开登录页面
   - 点击 × 或背景关闭弹窗

### 用户已登录时
1. 用户点击功能模块
2. 直接导航到对应功能页面

## 技术实现

### 认证状态检查
```typescript
const token = useAuthStore((state) => state.token)

if (!token) {
  // 显示登录提示弹窗
  setShowLoginPrompt(true)
  return
}

// 已登录，导航到模块
navigate(module.route)
```

### 登录流程
使用与 LoginButton 相同的登录逻辑：
- HMAC-SHA256 签名
- 浏览器轮询机制
- Token 和用户信息持久化

## 响应式设计

### 桌面端 (≥768px)
- 弹窗宽度：最大 500px
- 按钮高度：16px 字体，16px 内边距

### 平板端 (480px - 768px)
- 弹窗宽度：90%
- 按钮高度：14px 字体，14px 内边距

### 手机端 (<480px)
- 弹窗宽度：95%
- 按钮高度：14px 字体，14px 内边距

## 深色主题支持

弹窗自动适配深色主题：
- 背景色自动切换
- 文字颜色自动调整
- 按钮颜色反转（深色主题下为白色背景）

## 测试建议

1. **未登录状态测试**
   - 清除本地存储的 token
   - 点击任意功能模块
   - 验证弹窗是否正确显示

2. **登录流程测试**
   - 在弹窗中点击"立即登录"
   - 验证浏览器是否打开登录页面
   - 完成登录后验证 token 是否保存

3. **已登录状态测试**
   - 完成登录后
   - 点击功能模块
   - 验证是否直接导航到对应功能

4. **弹窗交互测试**
   - 测试关闭按钮
   - 测试背景点击关闭
   - 测试多次打开弹窗

5. **响应式测试**
   - 在不同屏幕尺寸测试弹窗显示
   - 验证按钮和文字是否正确缩放
